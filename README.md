# 🏥 Hospital Patient Data Analytics & Healthcare Operations Dashboard

## 📌 Project Overview

This project focuses on analyzing hospital patient data and healthcare operations using **Excel, SQL, and Power BI**. The interactive dashboard helps explore patient demographics, department performance, diagnosis patterns, and hospital operations to generate meaningful insights and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze patient distribution across hospital departments.
- Explore patient demographics and diagnosis patterns.
- Evaluate department-wise hospital performance.
- Monitor average Length of Stay (LOS) and treatment costs.
- Identify operational patterns and opportunities for improvement.
- Present actionable insights and recommendations through an interactive dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel** — dataset preparation
- **SQL** — data querying and analysis
- **Microsoft Power BI** — dashboard development and visualization
- **Power Query** — data transformation and cleaning
- **DAX** — calculations and analytical measures
